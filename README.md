# Sistema de Gestión Académica con Programación Orientada a Objetos
Proyecto de la Actividad colaborativa N.º 1 — Universidad de Manizales.

Sistema en Python que modela personas, programas y asignaturas de una institución educativa, aplicando clases, encapsulamiento, herencia, sobreescritura y polimorfismo.
